Penyiapan akun pilot lokal

Pilih akun lalu buka dialog Windows milik launcher. Isi kata sandi di dialog ABC MSA | Penyiapan akun lokal. Browser ini tidak menerima kata sandi setup.

Untuk mengubah kata sandi yang sudah disiapkan, dialog meminta kata sandi saat ini. Kata sandi Admin dan Superadmin harus berbeda. Tidak ada kredensial yang disimpan ke disk. Tutup dialog dengan Batal jika tidak diminta oleh Anda.

Kembali ke portal MSA

Stop menghapus konteks akun; restart memerlukan setup baru. Jika lupa kata sandi owner pilot, hentikan dan mulai ulang pilot fiktif.
